# 04 · 视觉设计规范

> 设计语言：**「信号绿指挥舱」--深空黑底 × 磷光信号绿。** 安全闸门是护盾，图谱是雷达。
> 唯一来源：所有组件只允许引用 `frontend/src/renderer/src/styles/tokens.css` 变量，禁止硬编码色值；新颜色先进本文件再进 tokens。

## 1. 色彩系统

### 1.1 表面层级（夜空黑，蓝调递进）

| Token | 值 | 用途 |
|-------|-----|------|
| `--void-0` | `#05070b` | 应用底色（最深） |
| `--void-1` | `#0b0f16` | 面板 |
| `--void-2` | `#0f1520` | 卡片 / 浮层 |
| `--void-3` | `#131b29` | 输入底 / hover 浅 |
| `--void-4` | `#1a2436` | hover |
| `--void-5` | `#26324a` | 活动 / 选中底 |

层级心法：界面像深夜的海面，越往上（浮层）越亮；同一层内用透明度线（`--line-*`）区分边界而非加框。

### 1.2 文字

| Token | 值 | 用途 |
|-------|-----|------|
| `--ink` | `#d7e1ec` | 主文字（冷白） |
| `--ink-dim` | `#8fa0b4` | 次要 |
| `--ink-faint` | `#5a6a7e` | 弱化（仅非关键信息，注意对比度） |
| `--ink-strong` | `#f4f8fc` | 强调 |

### 1.3 品牌与语义

- **品牌：磷光信号绿** `--accent: #2ee6a8`（= 安全 = 信任）。这是全产品唯一的高频品牌色，克制使用：主按钮、安全信号、点亮态。**绿色在产品语义里属于"闸门/安全"，不做普通装饰**。
- 语义色（闸门三色 + 扩展）：

| Token | 值 | 语义 |
|-------|-----|------|
| `--green` | `#35d99a` | ALLOW / 只读 |
| `--amber` | `#ffb454` | REVIEW / 警告 / 爆炸半径高亮 |
| `--red` | `#ff6b81` | BLOCK / 危险 |
| `--blue` | `#63c8ff` | 信息 / 构建态 |
| `--violet` | `#b18cff` | 辅助（用户自定义边等） |
| `--orange` | `#ffab70` | 辅助 |

- 使用规则：语义色只用于语义（REVIEW 永远 amber，BLOCK 永远 red），**禁止**拿语义色做装饰渐变；颜色永远配合图标 + 文案（见 03 §7）。

### 1.4 亮色主题（次要变体）

默认深色。亮色（`data-theme='light'`，日光图纸风）作为次要变体维护：新组件必须双主题各过一遍视觉验证（现有 `npm run screenshot` 体系）。**星图例外**：星图永远深空呈现（自带背景层），亮色主题下它是"深色舷窗"效果，属于刻意设计。

## 2. 字体

| Token | 栈 | 用途 |
|-------|-----|------|
| `--font-display` | Instrument Sans, PingFang SC, Microsoft YaHei | 标题 |
| `--font-sans` | 同上 + 系统 fallback | 界面正文 |
| `--font-mono` | JetBrains Mono, SFMono, Menlo, Consolas | SQL / 数据 / 数字 / 徽标 |

字号阶梯：`--fs-1:11px`（辅助）`--fs-2:12px`（正文小）`--fs-3:13px`（正文）`--fs-4:14px`（强调正文）`--fs-5:16px`（卡片标题）`--fs-6:20px`（区块标题）`--fs-7:30px`（页面标题）。

- SQL 一律 mono + 语法高亮（关键字 accent 或蓝、字符串橙、数字紫、注释 ink-faint）。
- 表名/列名在正文中出现时用 mono + `--ink-strong` 微高亮，形成"数据元素即代码元素"的视觉语言。

## 3. 形状 / 间距 / 阴影 / 层级

- 圆角：`--r-sm:8px`（输入/小卡）· `--r-md:10px`（按钮）· `--r-lg:14px`(面板/浮层) · `--r-full:99px`（胶囊/徽标）。
- 间距：4px 基数（`--sp-1..5` = 4/8/12/16/24），组件内用小值、组件间用大值，禁止非基数间距。
- 阴影两级：`--shadow-1`（普通浮层）、`--shadow-2`（模态）--深色主题阴影配 1px 半透明描边（内置）替代亮色投影。
- z-index 语义层：`--z-sticky:30` · `--z-pop:60` · `--z-modal:90` · `--z-drawer:100`，禁止随手写 999。

## 4. 组件风格

- **玻璃拟态**：浮层（SQL 卡 / 思考面板 / 风险面板）用 `backdrop-filter: blur(10px)` + 半透明底 + 顶部一条 4.5% 白色光带（现有 `.sql` 卡样式）。深空中玻璃 = "悬浮在数据上层的仪表"。
- **微交互**：hover 上浮 1px（`translateY(-1px)`）、按压回落缩放 0.98；一律 `transition: all .18s var(--ease)`。
- **入场**：卡片 `card-in`（10px 上滑淡入，340ms）；一次只让一个元素动，禁止满屏齐动。
- **徽标 / chips**：mono 小字、胶囊形、语义色 dim 底（如 `--amber-dim`）；数据元素 chips（表名等）永远 mono。
- **空态插画**：细线条 + 信号绿点缀的雷达/星图意象（与产品隐喻一致），禁止卡通插画。

## 5. 星图专用视觉（Graph3D，已实现基线）

- **背景**：自绘深空--径向渐变 `#0c1322 -> #070b13 -> #04060b` + 四团低透明星云（青 `rgba(76,201,240,.05)` / 紫 `rgba(139,124,248,.05)` / 信号绿两团 `.035/.025`）。星云透明度 **≤ .05**，宁淡勿艳。
- **星星**：130 颗，0.35 倍视差旋转 + 正弦闪烁，尺寸 0.6-1.9px，亮度 0.2-0.75--远景氛围，不与节点争夺注意力。
- **天球赤道环**：`rgba(110,150,190,0.09)` 1px 椭圆，存在感极弱的参照线。
- **节点**：
  - 调色板（表名哈希稳定取色）：`#4cc9f0` `#34f5c5` `#ffc46b` `#8b7cf8` `#ff8fb3`。
  - 半径 5-25px 对数映射行数；柔光 halo（点亮 .3 / 常态 .08-.2 透明度同色渐变）。
  - 景深明暗：透明度 0.35-0.7 随 z 深度渐变（近亮远暗）。
- **点亮态**：焦点节点白色光环（`.95`）+ 白色径向 glow；直连邻居满亮 + 白 `.6` 描边；相关边 `rgba(52,245,197,0.75)` 1.8px + 流动光点；无关元素全部压暗（alpha ≤ .35）。**点亮 = 信号绿系，压制其他一切颜色**。
- **爆炸半径联动（A3/P2 预留）**：直接波及表 amber 高亮、级联边红 `.75` 闪烁（≤2Hz，注意 03 §7 reduced-motion 时改静态高亮）。
- 节点标签：600 字重、9.5-12px 随景深、深色阴影底（`rgba(5,7,13,.9)` blur 5）保证任何背景上可读。

## 6. 动效总则

- 统一缓动 `--ease: cubic-bezier(0.22, 0.8, 0.24, 1)`、时长 `--dur: 160ms`（微交互）/ `340-420ms`（入场/布局变化）。
- 星图飞行 / 散开等长动画 ≤ 1.2s，一律可被交互打断。
- 动效目的只有三种：反馈（点了有响应）、引导（视线跟随变化）、氛围（星图）。装饰性动画一律砍。
- `prefers-reduced-motion`：全部动效退化为瞬时状态切换（星图停止自转，见 03 §7）。

## 7. 图标

- 风格：细线条（1.5px stroke）、圆角端点、几何直给的通用 icon 集（推荐 lucide 风格，可自绘）。
- 安全三态图标固定：ALLOW=盾牌+勾、REVIEW=盾牌+叹号、BLOCK=八边形斜杠。一旦出现即承载语义，禁止复用于非安全场景。
