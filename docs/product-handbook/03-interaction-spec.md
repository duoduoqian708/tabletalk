# 03 · 交互设计规范

> 原则：给 DBA 控制台，给业务提问框（两个第一屏）；键盘优先；一切危险操作先看见后果再确认。

## 1. 信息架构与两个第一屏

```
应用
├── 提问视图（业务用户的"第一屏"）
│   ├── 星图（数据宇宙 / 导航）
│   ├── 对话轨（AI 轨：提问 -> 思考流 -> SQL 卡 -> 结果 -> 追问链）
│   └── 问题库 / 模板（猜你想问）
├── 工作台（开发者的"第一屏"）
│   ├── SQL 编辑器（实时闸门检查 C1）
│   ├── 结果表 / 报告视图
│   └── 星图（可切换主视图）
└── 控制台（DBA 的"第一屏"，P2 起逐步成型）
    ├── 策略（A2）· 三档模式（B4）
    ├── 审计（含出网清单、异常信号）
    └── 成员 / 凭证 / 用量（P3）
```

- 单人模式：提问视图与工作台合一（现状布局：左图谱/编辑器 + 右 AI 轨），控制台折叠进设置抽屉。
- 团队模式（P3）：DBA 登录直接落控制台；业务用户落提问视图。**不要做成一个界面塞两种人**。

## 2. 全局交互

### 2.1 命令面板（Cmd/Ctrl+K，P1）

- 入口：全局快捷键，任何页面可唤起。
- 命令域：跳转表（schema 树 + 星图定位 D1 联动）、执行已保存问题（C6）、切换连接、新建对话、切视图（图谱/表格）、打开设置页。
- 交互：模糊匹配、最近使用置顶、键盘全程可达（上下选择 / 回车执行 / Esc 关闭）。
- 定位：开发者的效率入口，也是"键盘优先"原则的载体。

### 2.2 键盘优先

- 编辑器：Cmd+Enter 执行、Cmd+Shift+F 格式化（现有 /sql/format）。
- 对话：Enter 发送 / Shift+Enter 换行；Esc 打断生成（**待建**：现有 `/query/cancel` 只覆盖查询执行，AI 对话流的生成中断是新增能力，随 P1 落地）。
- 结果表：j/k 或方向键移动单元格（P2 可选）。
- 原则：高频动作必有快捷键；快捷键在 tooltip 中可发现。

### 2.3 反馈与等待

- AI 生成中：思考流（现有 SSE `think` 事件）逐条展示，绝不出现无反馈的转圈超过 300ms。
- 查询执行中：可取消（现有 /query/cancel），按钮态"取消"。
- 空态：每个空屏给"下一步动作"（提问框空态 = 猜你想问 C2；结果空态 = 建议改写）。
- 错误态：错误信息说人话 + 给恢复动作（"连接已断开 -> 重连"），不裸露堆栈。

## 3. 对话流（AI 轨）规范

一次完整问答的结构：

```
[用户问题]
[思考流（可折叠，默认展开最近 3 条）]
[SQL 卡：折叠态="显示查询"（C4）| 展开态=SQL 高亮 + 表/KB 引用 chips（C5）]
[结果摘要：行数 / 列 / 截断提示；报告模式=叙述 + 数字来源标注]
[追问链：2-3 个可点方向（C3）]
```

- **发送前**：出网清单（B1）折叠展示于发送按钮旁，一行文案 + 可展开明细。
- **REVIEW 语句**：SQL 卡内嵌确认条（预览行数 + 爆炸半径卡片入口 A3 + 回滚剧本入口 A4 + 确认/取消）；确认按钮文案带后果（"确认更新 238 行"）。
- **BLOCK 语句**：红色卡 + 拦截原因列表（A1）+ "如需执行请复制到编辑器手动运行（DDL 边界）"。
- 会话历史：点击历史会话不更新 `updated_at`（现有行为，保持）；会话可重命名、可固定。

## 4. SQL 编辑器规范（C1 实现基准）

- 实时检查的呈现层次（不打断输入为最高优先）：
  1. 装饰性：已知表/列绿色下划线（弱），悬停弹列卡片（列名 / 类型 / 注释 / 行数）。
  2. 警告：黄色波浪线（未知列 + 建议；无 WHERE 更新），行号旁图标，悬停显示"执行时将触发 REVIEW（规则文案与 A1 完全一致）"。
  3. 错误：红色波浪线（语法错误 / 多语句混合写）。
- **编辑器文案与闸门裁决同源**（共享规则 ID），用户在编辑器看到什么，执行时就发生什么。
- lint 异步、防抖 < 150ms，绝不阻塞输入。

## 5. 星图交互规范（Graph3D，含已定行为基线）

> 本节是**行为规格**，改动需回改本文档。现有实现已按此基线修复并经 e2e 验证。

### 5.1 基础行为（已实现，勿回退）

| 交互 | 行为 |
|------|------|
| 拖拽 | 旋转视图（惯性 + 衰减 0.93/帧） |
| 滚轮 | 缩放 0.5x–2.4x |
| 单击节点 | 选中：白环 + 该节点与直连邻居点亮、相关边变 teal；弹信息卡（表名/行数/列数/FK 数 + 查看数据） |
| 单击空白 | 关闭信息卡、清高亮 |
| hover | 仅改指针形状，**不抢占选中高亮**（历史 bug，禁止回退） |
| 拖拽后松手 | 不触发选中（防误选） |
| 惯性漂移中轻点 | 仅止停，不选中（防误选） |
| 命中判定 | 按深度近->远（画家算法），被遮挡的背侧节点不可点中 |

### 5.2 自转（"灵动"基线，已实现）

- 默认自转速度 0.0016 rad/帧（约 70 秒一圈）。
- 任何交互（按下 / 拖拽 / 滚轮）即停转（命中判定需要静止画面）。
- 静止 1.2s 后自转速度以 0.02/帧缓升恢复--**平滑淡入，禁止猛启**。
- 原因记录：曾因"点击后永久停转"被用户报失去灵动感；参数调整需连同此背景一起评估。

### 5.3 增强交互（见 02-D 系列）

- D1 搜索定位：输入表名 -> 飞行至节点（缓动，可打断）。
- D2 显式暂停/恢复按钮：与隐式行为共存。
- D3 选中邻居局部散开：1s 缓动、可打断、防抖（连续切换不抖）。
- D4 Onboarding 首次飞行：任意交互打断，本地记忆永不重放。

## 6. 确认流与危险操作

- 三级确认强度（与闸门三档对齐）：
  - **READ**：无确认。
  - **REVIEW（DML）**：一次确认，确认界面必须同时呈现：影响行数预览、爆炸半径（A3）、回滚剧本（A4）。按钮文案带具体后果（"确认更新 238 行"），不用"确定/OK"。
  - **BLOCK（DDL 等）**：红牌强确认--红色面板、输入表名确认（或按住 2s），文案说明为什么拦、放行路径（DDL 一律引导去编辑器手动执行）。
- 只读连接的写操作：直接红牌（现状行为保持），说明"此连接为只读"。
- 一切确认动作写审计（语句、裁决、是否确认、时间）。

## 7. 无障碍与舒适度

- 尊重 `prefers-reduced-motion`：关闭星图自转与飞行动画，改为静态可拖拽。
- 星图提供显式暂停（D2）--动效眩晕用户的逃生门。
- 焦点管理：弹层（确认 / 信息卡）打开即聚焦，Esc 关闭，焦点归还触发元素。
- 颜色不是唯一信号：BLOCK/REVIEW 除颜色外加图标与文案（同时服务色弱用户与黑白打印场景）。
- 对比度：正文 ≥ 4.5:1，界面大字 ≥ 3:1（深色主题下重点检查 ink-faint 的使用场景）。

## 8. 国际化

- 全部 UI 文案走现有 i18n 词典（中/英），新增功能文案**先入词典再写组件**（禁止内联硬编码文案）。
- 规则文案（A1）、策略描述（A2）等安全类文案双语是硬要求（开源传播 + 企业采购方常为英文环境）。
- 日期/数字格式跟随 locale。
