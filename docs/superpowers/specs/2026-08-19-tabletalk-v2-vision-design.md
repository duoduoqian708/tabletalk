# tabletalk V2 · 产品愿景与总体设计

> 日期：2026-08-19 · 状态：已与用户逐项确认（形态/视觉/图谱职责/AI交互/技能机制）
> 本文是 V2 的**总纲**。落地按 §10 子项目分解，每个子项目单独出实施计划。

## 1. 背景与目标

用户对 V1 的三点不满：
1. **风格太 low**——不是换配色，是产品形态与视觉语言整体重构（功能一个不砍）；
2. **特色没立起来**——AI 交互区机械死板；知识库/图库（NL→SQL 的底座）设计得不像主角；
3. **工具×技能没有解耦**——组合关系固定、扩展成本高，期望任意组合、玩法多样。

V2 的交付物是一版**形态重构**的 tabletalk：图谱画布工作区 + Void 深空极简视觉 + 自然化 AI 交互 + 用户可编排的技能体系。所有 V1 功能保留：连接管理、安全闸门、审计、报告模式、知识库、设置、AI 对话。

## 2. 产品形态：图谱画布工作区

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏: ◈ tabletalk │ demo.db ▾ │ ⌘K 搜索 │ gate armed │ 模型 │ ⚙   │
├──────────────────────────────────┬───────────────────────────┤
│ 主区（图 ⇄ 表 双视图）            │  AI 停靠栏（固定右侧）     │
│                                  │                           │
│  [浏览|搭查|治理]  单击=检查器    │  自然对话流               │
│  ◉ 节点=表  ──FK──> ◉ 节点       │  上下文筹码（随选中联动）  │
│  ▤ 查询节点        ◉ 节点        │  SQL卡片（就地可编辑）     │
│  双击=打开数据   右键=更多        │  主动建议条               │
│  ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄│  输入 @表名 聚焦           │
│  表格视图: 左缘微条(回图+关联跳转) │  (可折叠成窄条,默认展开)   │
└──────────────────────────────────┴───────────────────────────┘
```

### 2.1 顶栏
连接下拉（含只读 badge）、⌘K 全局搜索、gate 状态、当前模型（provider 名 + 模型 ID）、设置、审计入口。

### 2.2 主区双视图
- **图谱视图**（默认，⌘1）：画布即工作区。
- **表格视图**（⌘2）：全屏数据表格；图谱收成**左缘 36px 微条**——顶部"回图谱"按钮 + 关联表跳转点（当前表的 FK 关联表，点击直接切换表格）。
- 主区工具栏：`[图谱 | 表格]` 切换 + 面包屑（库 / 表）。

### 2.3 AI 停靠栏（固定右缘）
默认展开（~320-360px），可折叠成窄条（默认不折叠）。见 §6。

### 2.4 旧页面去向
| V1 页面 | V2 去向 |
|---|---|
| 工作区（SchemaRail + DataTable + AiRail） | 主区双视图 + AI 停靠栏；SchemaRail 被图谱吸收 |
| 知识库审查页 | 图谱**治理模式** + 检查器 |
| 图谱页 | 主画布本体 |
| 审计页 | 顶栏入口（独立视图保留，换新皮肤） |
| 设置抽屉 | 保留，换新皮肤 + 新增技能广场 tab |

## 3. 视觉语言：Void 深空极简（可换主题）

- 近黑底 `#0a0b0e` / 面板 `#0d0e12` / 卡片 `#14161d`；发丝线边框 `rgba(255,255,255,0.07~0.14)`；
  单一电光紫强调 `#7c8cff`；正文 `#e8eaf0` / 次要 `#8b93a3` / 弱化 `#5b6472`。
- **域色体系**（图谱专用）：交易域紫 `#7c8cff`、用户域绿 `#6ee7b7`、商品域琥珀 `#f6ad55`（由知识库领域标签驱动，可扩展）。
- **设计令牌**：全部颜色/圆角/阴影/间距/字体收敛为 CSS 变量（`frontend/src/renderer/src/styles/tokens.css`）。
  未来加浅色主题 = 换一套令牌，零组件重构。设置里"主题风格"占位在令牌体系完成后激活（V2 先只交付 Void 深色）。
- 字体：Inter（界面）+ JetBrains Mono（SQL/数据/数值/徽章）。
- 图形化资产：节点卡片（域色点+表名+元信息）、选中发光（feDropShadow 风格，CSS filter）、虚线=待注释、点状网格画布、FK 边标注。

## 4. 图库（核心玩法）：一张图，三种模式

| 模式 | 定位 | 关键交互 |
|---|---|---|
| **浏览**（活地图） | 30 秒读懂库 | 悬停/单击=检查器（字段/注释/预览）；域色；注释状态 ✓/⚠/✗；FK 边标注 |
| **搭查**（积木台） | 图上搭查询 | 点选节点→自动 JOIN 骨架→让 AI 补条件；已执行的查询/报告沉淀为**查询节点**（可复用、可重跑） |
| **治理**（策展） | 知识越用越准 | 待确认注释/标签在图上直接确认/驳回；知识健康度一目了然（未注释表、待确认项） |

- **节点**：表（域色点、字段数、注释状态）；查询节点（虚线紫框、来源 SQL、报告标记）。
- **边**：FK 关系，带标注（`customer_id`）；选中节点时相连边高亮。
- **孤表**（无 FK，如 app_config）：正常显示，无连线，双击即看数据。
- **布局算法**：力导向 + 域分组（同域节点聚类），首版可先用简单网格/同心圆兜底，力导向为增强项。
- **交互约定**：单击=选中+检查器；双击=打开数据（表格视图）；右键=更多（问 AI、搭查询、打开数据、生成 DDL 草稿、治理…）；空白处拖拽平移、滚轮缩放、缩略导航（⤢ 全览）。

## 5. 表格视图与结果（数据一键直达，零 AI）

- 双击节点 / 检查器"打开数据" → 表格视图：筛选、列设置、排序、分页（复用 V1 的 preview 能力 + 分页增强）。
- **多标签结果**：数据浏览 / AI 查询 / 报告并存（替代 V1 单实例 result）。每标签：来源（表 / SQL+问题 / 报告标题）、行数、耗时、导出 CSV。
- 单元格可复制；表头点击排序；空态/错误态有明确文案。
- AI 查询结果落主区表格（而不是聊天里），聊天里保留摘要 + "打开结果"入口。

## 6. AI 交互区（四条病根 → 四个响应）

| V1 病根 | V2 响应 |
|---|---|
| 表现形式太碎（步骤条/徽章/开关堆砌） | 去除四步阶段条与徽章堆砌；思考过程折叠为轻量一行（"思考中…"可展开），不打断对话流 |
| 上下文割裂 | 选中节点自动变**上下文筹码**（`上下文：orders ✕`，可移除/追加多个）；`@表名` 聚焦；AI 结果直接进主区 |
| 不可迭代 | SQL 卡片**就地可编辑**（改完重跑）；可追问（对话自然延续）；可比对（新结果与上一版结果对照） |
| 太被动 | **主动建议条**（基于当前上下文生成："按月看回款趋势？"），一键采纳为提问 |

- 输入区：占位文案、发送键；技能徽章（当前技能名）；模型/思考开关收敛进设置，对话区不再堆控件。
- **安全不变式不动**：只读自动执行、DML 人工确认、DDL 永远草稿（AI 无 DDL 执行工具）、闸门模型无关、读连接硬禁止写。

## 7. 知识库（底座，后端全保留）

- 后端 `app/knowledge/`（结构+向量+图谱+注释+标签+路由）**零删除**，仅按需加 API（如检查器按表取注释、治理批量确认）。
- 前端形态：注释/标签/文档浮在**检查器**（可编辑）；确认/驳回流在**治理模式**的图上完成（替代 V1 知识审查页）。
- 知识健康度：治理模式顶部统计（待确认注释数、待确认标签数、未注释表数）。
- 语义检索与标签路由照旧（confirmed-only 路由不变）。

## 8. 数据源接入（连接管理）

- 连接管理保留（模态框），纳入新设计系统：dialect、host/port、库名、用户/密码、只读开关、连接池、测试连接。
- 支持 sqlite/postgres/mysql（`DialectAdapter` 注册表，新增方言零上层改动——V1 已去硬编码）。
- **连接后首屏即图**：连接成功 → schema 发现 → 图谱自动生成（无需手动"构建知识库"）；知识库构建仍懒加载。
- 连接切换：顶栏下拉；切换后图谱/表格/上下文按连接隔离（V1 chat store 已按连接存会话，沿用）。
- 只读连接：连接菜单与顶栏显示只读 badge；写操作硬拦截（后端已实现，保留）。

## 9. 大模型接入与技能体系

### 9.1 模型接入（保留 + 新皮肤）
- 设置内模型管理保留：自配 provider/base_url/api_key/model、测试连接（能力探测：function_calling/reasoning/streaming）、温度滑条、key 脱敏、推理徽章。
- mock 兜底逻辑保留（`is_effective_mock`；`/ai/test` 禁用兜底以暴露真实问题）。
- 顶栏/停靠栏头部显示 provider 名 + 模型 ID（V1 已加 `ai_provider_name`）。

### 9.2 工具 × 技能解耦（用户可编排）
- **工具 = 原子积木**（`app/ai/tools/` 注册表，V1 已有 5 工具）：get_schema / describe_table / run_query / run_dml / draft_ddl；新增小工具：preview_count、format_sql、list_tags 等（按需）。
- **技能 = 剧本**（编排工具的声明式组合）：内置 query / report / 搭查 / 治理；技能 = 触发条件（意图关键词）+ 剧本（工具序列 + 提示词）+ 元信息。
- **技能广场**（设置内新 tab）：技能清单（启用/禁用/默认技能）、勾选工具组合（该技能可用哪些工具）、**自建简单技能**（选工具 + 写提示词 + 设触发词）。
- 运行时：现有 dispatcher 演进为**剧本执行器**（按剧本步进调用工具，步骤间可插入 LLM 判断）。
- **安全硬约束**：组合层校验——任何技能/工具组合不能绕过闸门；AI 工具集永无 DDL 执行工具；工具参数在执行前过闸门（沿用 run_query/run_dml 的 gating）。

## 10. 技术路线与代码改造路径

### 10.1 前端
- 状态：zustand 不变；新增 `useGraph`（画布状态：节点/边/视口/选中/模式）、`useTabs`（结果多标签）替代单实例 result/report。
- 画布：**自研轻量引擎**（无第三方图库）：SVG 节点/边渲染 + 视口变换（缩放/平移）+ 力导向布局（可选增强）+ 模式状态机。规模控制 ~1500 行。
- 骨架改造顺序：AppLayout 拆顶栏/主区/AI停靠栏 → SchemaRail 退役（被图谱吸收）→ AiRail 重构（对话流）→ 知识页/图页并入模式 → DataTable 增强（分页/列设置/多标签）。
- 样式：tokens.css 全量重写（令牌化）；app.css 按组件收敛；boot.css 保留启动屏。

### 10.2 后端
- `app/ai/tools/`、`app/ai/skills/` 注册表**演进**：skills 增加声明式剧本模型 + 校验；dispatcher 增加剧本执行器分支。
- 新增 API：`GET/PUT /api/v1/skills`（清单/启用/组合）、`POST /api/v1/skills`（自建）、技能执行事件保持 SSE 通道。
- 知识库：新增按表取注释/标签、治理批量确认端点（小改）。
- 全部改动过 pytest（V1 基线 184 passed + 新增用例）。

### 10.3 兼容与回归
- 每子项目完成门槛：前端 typecheck + build 全绿；后端 pytest 全绿；重启 sidecar；浏览器手测关键路径（连接→图→双击数据→AI 提问→审计）。

## 12. 决策记录（AD）

- AD-1：图谱画布**自研**，不引第三方图库（依赖可控、与视觉系统融合度最高；力导向算法可后补）。
- AD-2：表格视图**替换**底部抽屉方案（用户拍板：数据是干活区，图收成左缘微条，不用悬浮小地图挡数据）。
- AD-3：AI 区**固定右缘**常驻（用户拍板），可折叠但默认展开。
- AD-4：主题系统从第一天**令牌化**（V2 交付 Void 深色；浅色主题后续换令牌即可）。
- AD-5：技能对用户**可编排**（技能广场 + 工具勾选 + 自建简单技能），但安全闸门不可绕过。
- AD-6：V1 全部后端能力**零删除**，只演进与增补 API。
